# Копия для восстановления сайта от 14.11.2026

- Архив файлов содержит 4 доступных изображений, документов и видео из `wp-content/uploads` и активов тем. Пути внутри архива начинаются с `uploads/` или `themes/` относительно `wp-content`.
- JSON содержит 4 опубликованных записей разрешённых типов, тексты, даты, адреса и ID. Экспорт не содержит настроек базы, аккаунтов, заявок и черновиков. Это рабочие данные для переноса контента. Для точного восстановления настроек WordPress нужен полный SQL или физическая копия.
- Сначала проверьте `sha256sum -c PARTS.sha256`. Соберите архив командой `cat files.tar.gz.part-* | tar -xzf - -C /путь/к/временному-каталогу`. Проверьте распакованное по `SHA256SUMS` из этой папки.
- Для контента выполните `sha256sum -c CONTENT-PARTS.sha256`, затем `cat posts.json.gz.part-* | gzip -dc > posts.json`. SHA-256 результата указан в `CONTENT.sha256`.
- Темы, плагины, параметры сайта и служебные данные восстанавливайте по [инструкции «Сервер»](https://github.com/suyazov/affine-pages-backup/blob/main/affine/infrastructure/Сервер.md).
